# Школьный калькулятор v4.0.1

## Новая публикация

Распакуйте архив и загрузите файлы в корень отдельного репозитория. Settings → Pages → Deploy from a branch → main → /(root) → Save. После публикации откройте ссылку Visit site в Safari.

## Обновление существующего сайта

Замените index.html и browser-check.html файлами из этого архива. Адрес сайта менять не нужно. Уже введённые данные браузера сохранятся; очищать их не требуется.

## Добавление имеющейся статистики

Файл со школьной статистикой предоставляется отдельно в JSON. Не загружайте его в публичный GitHub. Сохраните JSON на устройстве, откройте сайт → Оценки → Загрузить сводку → выберите JSON → Сохранить. Годовая статистика появится на главной и в журнале. Эта операция добавляет сводку, сохраняя оценки, домашние задания, настройки и историю.

Годовая сводка хранится отдельно от месячного среднего и не создаёт оценки с выдуманными датами. Она не изменяет денежную формулу. Для месячного расчёта нужны отдельные оценки с датами и подтверждённые домашние задания.

Данные хранятся в браузере устройства. Автоматической синхронизации нет. Ещё → Экспорт JSON позволяет сохранить полную копию, включая сводки.

## Проверки

Пройдено 42 расчётных и 23 программных UI-проверки. Прямое тестирование в браузере среды разработки недоступно. Страница browser-check.html содержит отдельную браузерную проверку, которая использует тестовую базу и не изменяет семейные записи.
