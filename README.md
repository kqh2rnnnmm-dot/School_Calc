# Школьный калькулятор v4.0

## Размещение на GitHub Pages

1. Создайте отдельный публичный репозиторий, например school-calculator.
2. Распакуйте архив. Загрузите файлы в корень репозитория: index.html и browser-check.html; .nojekyll — если он отображается. Сам ZIP загружать не нужно. Файл index.html должен быть в корне, не во вложенной папке.
3. Откройте Settings → Pages. Source: Deploy from a branch. Branch: main, папка /(root). Нажмите Save.
4. Дождитесь завершения публикации. В Settings → Pages появится ссылка Visit site. Откройте её в Safari на iPhone.
5. При желании используйте меню Поделиться → На экран «Домой».

Приложение находится целиком в index.html. Внешние библиотеки, API-ключи и серверные функции не нужны. Формула и функциональность соответствуют локальной версии v4.0.

Данные хранятся в браузере устройства и не отправляются в репозиторий. Между устройствами они автоматически не синхронизируются. Резервная копия: Ещё → Экспорт JSON. Если уже есть данные в локальной версии, экспортируйте их там и импортируйте на опубликованном адресе.

## Браузерная проверка

На адресе сайта откройте browser-check.html и нажмите «Запустить проверки». Проверка работает с отдельной тестовой базой и не меняет семейные записи. В среде разработки настоящая браузерная проверка была недоступна; фактически выполнены 35 расчётных и 19 программных UI-тестов.
